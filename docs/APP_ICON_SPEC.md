# App Icon Specification: FlipVoice

## Concept & Visual Identity
- **Central Metaphor:** A symmetrical soundwave looping back on itself, or a tape reel with two opposing arrows forming a dynamic infinity/loop symbol.
- **Color Palette:**
  - Background: Deep Obsidian / Dark Slate `#0F172A`
  - Primary Element: Electric Cyan `#06B6D4` to Neon Purple `#A855F7` linear gradient (45-degree angle).
  - Accents: Clean white audio waveform bars.

## Icon Dimensions
- **Master Size:** `1024 x 1024 px` PNG (Square, no rounded corners or transparency, sRGB color space).
- Target location in Xcode project:
  `FlipVoice/Resources/Assets.xcassets/AppIcon.appiconset/`
